# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Report vulnerabilities in this plugin through Entrust's responsible disclosure
programme:

<https://www.entrust.com/legal-compliance/security#responsibledisclosure>

Entrust's published vulnerability disclosure process governs how reports are
acknowledged and handled.

## Which project is affected?

This repository contains only the CA Gateway `UpstreamAuthority` plugin. SPIRE
itself is a separate project maintained by the SPIFFE community, which cannot
act on issues in this plugin.

| Where the flaw is | Report it to |
|---|---|
| This plugin | Entrust responsible disclosure, linked above |
| SPIRE, or the SPIFFE plugin SDK | The SPIFFE project — <security@spiffe.io> |

If you are not sure which applies, report it to Entrust and we will redirect it
if necessary.

## Supported versions

Security fixes are applied to the latest release. Please make sure you are on the
most recent release before reporting an issue.
